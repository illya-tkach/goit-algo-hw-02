# goit-algo-hw-02

Домашнє завдання до теми 2 «Основні структури даних».

## Завдання 1 — `task1_service_center.py`
Імітація роботи сервісного центру на основі `Queue` з модуля `queue`:
- `generate_request()` — створює заявку з унікальним номером і додає до черги;
- `process_request()` — видаляє заявку з черги та обробляє її або повідомляє, що черга пуста;
- головний цикл працює, поки користувач не введе `q` (або Ctrl+C).

```bash
python3 task1_service_center.py
```

## Завдання 2 — `task2_palindrome.py`
Функція `is_palindrome(text)` додає символи рядка до `deque` з модуля `collections` і порівнює їх з обох кінців. Працює для рядків з парною і непарною кількістю символів, нечутлива до регістру та пробілів.

```bash
python3 task2_palindrome.py
```
